# A Framework for Diabetes Detection Using Machine Learning and Data Preprocessing

## 📖 Overview

This repository contains the official implementation of the research paper **“A Framework for Diabetes Detection Using Machine Learning and Data Preprocessing.”**

The project presents a machine learning framework for **early diabetes detection**, integrating data preprocessing, feature selection, class imbalance handling, and model optimization to support reliable and reproducible predictions.

## 👥 Authors

* **Dr. Ahmad Adel Abu-Shareha**
* **Haneen Qutaishat**
* **Asma Al-Khayat**

## 🔬 Methodology

The proposed framework includes:

* **Data Preprocessing:** Cleaning and missing-value imputation.
* **Feature Selection:** Identifying relevant predictive features.
* **Class Imbalance Handling:** Applying oversampling techniques.
* **Model Training:** Training multiple machine learning classifiers.
* **Hyperparameter Optimization:** Tuning models for improved performance.
* **Evaluation:** Assessing classification and diagnostic performance.

## 🛠️ Technologies

* Jupyter Notebook (interactive development environment)  
* Pandas & NumPy (data preprocessing and manipulation)  
* Scikit-learn (machine learning algorithms and optimization)  
* Matplotlib & Seaborn (data visualization)

## 🎯 Objectives

* Develop a **robust and reproducible** framework for early diabetes detection.
* Improve predictive performance through effective data preprocessing and feature selection.
* Address class imbalance and optimize machine learning models.
* Provide a **transparent implementation** of the proposed research methodology.
